# Sakura Wars V: Episode 0 — PS2 English Translation

**Japanese title:** Sakura Taisen V Episode 0: Kouya no Samurai Musume (サクラ大戦V EPISODE 0 ～荒野のサムライ娘～)

**Platform:** PlayStation 2

> **Status (November 28, 2026): English translation and integration completed — entering private Beta testing.**

## About the game

Sakura Wars V: Episode 0 is a PlayStation 2 action-adventure prequel to *Sakura Wars: So Long, My Love*. Its protagonist is Gemini Sunrise, traveling across America with her horse Rally. Unlike the main Sakura Wars strategy games, Episode 0 features action-focused gameplay along with story conversations and LIPS choices.

The Japanese PlayStation 2 version was released in 2004.

## English Translation — Beta Handoff

My translation and editing work has reached a cumulative testing build, and the project is now **entering private Beta testing**.

This build includes English work on:

- Story and character dialogue (approximately 2,122 dialogue entries)
- Timed dialogue choices and LIPS (approximately 122 choices)
- Menus, system messages and user interface
- Title/logo and relevant graphical text
- Tutorials and gameplay instructions
- Cinematic / presentation resources and credits

The cumulative patch is the development basis for the new Beta. These totals describe the current translated resources, **not verified full-playthrough completion**.

## What the Beta Testers Should Check

- Full game progression and completion in PCSX2
- Context, names, wording and dialogue consistency
- LIPS choices and timing
- Text overflow, clipping and menus
- Remaining Japanese text or graphics
- Cinematics, subtitles and dialogue/audio timing
- Crashes, freezes and progression-blocking problems

Please provide screenshots, the relevant chapter or mission, the emulator version if possible, and clear reproduction steps.

**This is a private Beta, not a public release.** A final release date has not been announced.
