# Sakura Wars: In Hot Blood — PlayStation 2 English Translation

*Sakura Taisen: Atsuki Chishio ni* (PlayStation 2)

> **Status (November 27, 2026): Menu and interface translation in progress. Story dialogue has not yet been ported.**

## About the Project

This is a separate English localization project for the **PlayStation 2 remake of the original Sakura Wars**. It is not the same project as [Sakura Wars 1 for Sega Dreamcast](https://github.com/wakabayashy/Sakura-Wars-1-Dreamcast-English-Translation).

I have begun translating the **PS2 menus and interface only**. The initial screenshots show English interface work, not a completed story translation.

## Translation and Integration Plan

Rather than translating the original story twice, I intend to use the English text from my Dreamcast translation once that project finishes its current private Beta testing.

1. **Finish Sakura Wars 1 Dreamcast Beta testing:** Collect tester reports, check context, fix remaining text and technical issues.
2. **Port the validated English text:** Adapt the finalized Dreamcast English translation to the PS2 remake's files, presentation and interfaces.
3. **Translate PS2-exclusive content:** Translate and edit the additional dialogue and scenes in the remake that are not present in the Dreamcast version.
4. **Integrate and validate:** Perform in-game checks and corrections before announcing a PS2 Beta.

This preserves the terminology and corrections from the finished Dreamcast project, while covering the remake's additional content.
