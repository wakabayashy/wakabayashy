## 🗡️ Hundred Swords — Sega Dreamcast

**Status: Official PC English translation port — Dreamcast adaptation and editing in progress**

This project ports the existing **official English PC translation** of Hundred Swords to the Sega Dreamcast. It is an adaptation of the existing PC localization, not a new translation from Japanese.

The English text is being transferred, adapted and edited for the Dreamcast version. Further technical work and validation are required before a public Beta or release can be announced. **No public patch is currently available, and in-game Flycast validation has not yet been completed.**

- **Source:** Official English PC version
- **Target:** Sega Dreamcast
- **Current work:** Porting, adaptation and editing
- [GitHub repository](https://github.com/wakabayashy/Hundred-Swords-Dreamcast-English)

## 🌸 Sakura Wars 1 — Sega Dreamcast

**Status: Translation complete — Beta testing in progress**

The English translation of the original Sakura Wars (Sakura Taisen) for Dreamcast has reached **100% of the text translation**. The project is now being tested by Beta testers.

This is an independent AI-assisted English translation made from the original Japanese Dreamcast game. It does **not** reuse or port the existing Sega Saturn English fan translation.

The translated content includes:

- Main story dialogue and character conversations
- Events and LIPS dialogue choices
- Menus and interface text
- Battle-related text
- Character information and system messages

The current Beta phase focuses on dialogue and contextual corrections, text formatting, LIPS choices, menus, battle interfaces, story progression, remaining Japanese text and technical issues.

**Beta access:** Private, available on request through Discord. Contact me to request access; I can authorize testers individually.

- [GitHub repository](https://github.com/wakabayashy/Sakura-Wars-1-Dreamcast-English-Translation)
- No public release has been announced yet.

## 🌸 Sakura Taisen: Atsuki Chishio ni (Sakura Wars: In Hot Blood) — PlayStation 2

**Status: Menus and interface translation in progress — story translation not yet ported**

This is my English localization project for the PlayStation 2 remake of the first Sakura Wars, separate from the Dreamcast project.

**Only the menus and interface have been worked on so far.** The first published screenshots illustrate this interface work. The story dialogue has not yet been ported.

### Planned workflow

1. Complete the Beta testing and corrections for **Sakura Wars 1 on Dreamcast**.
2. Port the validated Dreamcast English translation to the PS2 remake, adapting it to this version's resources and presentation.
3. Translate and edit the **new or PS2-exclusive passages** that are not covered by the Dreamcast translation.
4. Test the combined localization on PS2 after integration.

- **Platform:** PlayStation 2 (Japanese version)
- **Current work:** Menus and interface translation
- **Story/dialogue translation:** Awaiting finalized Dreamcast translation for porting
- **Additional PS2 content:** New passages to be translated later
- **Public Beta:** Not announced
- **Public release:** Not announced
- **Discord:** https://discord.gg/qf33SZmpn
- [Detailed PS2 project page and translation-port roadmap](https://github.com/wakabayashy/Sakura-Wars-In-Hot-Blood-PS2-English)
- **Dedicated GitHub repository:** [Sakura Wars: In Hot Blood — PS2 English](https://github.com/wakabayashy/Sakura-Wars-In-Hot-Blood-PS2-English)

## ⚔️ Langrisser Millennium — Sega Dreamcast

**Status: Beta testing in progress**

The English translation has reached public Beta builds, and further gameplay and hardware testing is ongoing.

The public repository currently documents:

- **Build 62:** Standard Beta 1 hotfix, recommended for non-VGA setups and emulators.
- **Build 63:** GDI/VGA hardware test build. Its VGA setup was confirmed working on NTSC-J Dreamcast hardware with GDEMU 15b and a VGA/HDMI connection.

Build 63 is a hardware compatibility test; Build 62 remains the recommended version for users who do not need VGA support.

The current Beta testing work focuses on finding remaining untranslated text, translation and context problems, graphical issues, line wrapping, event problems, crashes, freezes and hardware-specific issues.

**Beta access:** Private testing is also coordinated through Discord. Contact me to request access; I can authorize testers individually.

## ⚔️ Langrisser Millennium WS: The Last Century — Bandai WonderSwan

**Status: Complete — v1.0 released**

The complete English fan translation for the original monochrome Bandai WonderSwan has been released as **v1.0 in November 2026**.

The translation covers both routes, hidden stages, story and battle dialogue, menus, equipment, items, spells, mercenaries, deployment, save/load screens, class changes, endings and staff credits. The English text renderer and fonts were also adapted for the WonderSwan display.

Two optional BPS patch editions are available:

- **Standard English v1.0:** the complete English translation.
- **Test Stage Edition v1.0:** the same translation, with access to the hidden developer Test Stage.

Both editions are available in the v1.0 release. These are patches, not ROMs; users must provide their own original Japanese game.

- [GitHub repository](https://github.com/wakabayashy/Langrisser-Millennium-WS-English)
- [v1.0 release — both editions and release notes](https://github.com/wakabayashy/Langrisser-Millennium-WS-English/releases/tag/v1.0)
- [Standard English v1.0 patch](https://github.com/wakabayashy/Langrisser-Millennium-WS-English/releases/download/v1.0/langrisser-millennium-en-1.0.bps)
- [Optional Test Stage Edition v1.0 patch](https://github.com/wakabayashy/Langrisser-Millennium-WS-English/releases/download/v1.0/langrisser-millennium-en-teststage-1.0.bps)

This was a collaborative project. Special thanks to Cloogr, Last_Seraph and altaihero for their contributions, playtesting and bug reports.

## 🏯 Tengai Makyō: Ziria – Haruka Naru Jipang — Xbox 360

**Status: In development — approximately 50% of dialogue translated**

This is a project published under my name, with **Veiga117 as the main developer**.

Veiga117 is handling the actual translation, text editing, manual review, technical research, game integration and patch development. The project is released under my name; I provide support and coordination. All credit for the translation and technical work belongs to Veiga117.

According to his latest progress update, approximately **50% of the game's dialogue has been translated**. AI assistance is used to speed up the initial translation, but every dialogue will receive a manual review before release.

### Optional Quality-of-Life features

Veiga117 has found developer debug variables that can be used to investigate optional improvements:

- **Cutscene skipping:** force otherwise unskippable cutscenes to be skipped.
- **Dialogue speed-up:** make dialogue progress faster.

These features are intended to be optional. Initial testing has already started, although some crashes have been encountered and still need investigation.

### Future Beta testing

We expect to look for Beta testers once the dialogue translation reaches 100%. Manual review and further testing will still be necessary before release.

- Main developer: **Veiga117**
- Project / release: **wakabayashy**
- [GitHub repository](https://github.com/wakabayashy/Tengai-Makyo-Ziria-Xbox360-English)
